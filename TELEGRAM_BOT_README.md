# Telegram bot for theatre contacts

Бот ищет по тем же данным, что и страница `index.html`: имя, город, категория, роль, контакт и старые названия объединённых категорий.

## Быстрый запуск

1. В Telegram открой `@BotFather`.
2. Отправь `/newbot` и получи token.
3. В терминале из этой папки запусти:

```bash
export TELEGRAM_BOT_TOKEN="123456:your-token-here"
python3 telegram_bot.py
```

## Как пользоваться в Telegram

Напиши боту обычный запрос:

```text
актёр
звук
Лиссабон
фотография
Ласская
```

Команды:

```text
/start
/categories
/cities
/all
```

## Как дать доступ людям из чата

Пока `telegram_bot.py` запущен на компьютере или сервере, бот отвечает всем, кто ему пишет. Для постоянной работы его нужно держать на хостинге или на включённом компьютере. Статическую страницу `index.html` отдельно лучше выложить на GitHub Pages, Netlify или другой веб-хостинг: `file://` ссылка работает только на твоём компьютере.
